## Scripts

- **`copykit.R`** – Runs CopyKit on scWGS BAM files to generate cell-level CNV profiles.
- **`get_cont_gt_copykit_w_ploidy.R`** – Generates sample-level relative continuous pseudobulk CNV profiles from CopyKit using sample-specific ploidy.
- **`gene_to_bin100kb.R`** – Converts gene-level CopyKit pseudobulk CNV profiles to 100-kb bin-level relative continuous CNV profiles.
