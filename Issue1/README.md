## Scripts

- **`karyogram.R`** – Generates karyogram heatmaps for continuous and discrete CNV profiles to visualize genome-wide CNV patterns across methods.
- **`pearson_correlation.R`** – Computes Pearson correlations between inferred CNV profiles and ground truth, generates correlation heatmaps and paired comparison plots, and performs Wilcoxon signed-rank tests.

## Input data

For each sample, the `<sampleID>_combined_methods_ratio.rds` file is generated by retaining the intersection of columns (genomic bins) across the three result tables and then concatenating them by rows. The three methods, as shown in Fig. 1, are:

- **`Aneufinder_Schmid_R`** – results stored in `scDNA_Aneufinder/bin100kb_cont.zip`
- **`Aneufinder_Karyotyping`** – results stored in `scDNA_Aneufinder/bin100kb_cont_w_ploidy.zip`
- **`CopyKit_Karyotyping`** – results stored in `scDNA_CopyKit/bin100kb_cont_w_ploidy.zip`

The resulting `<sampleID>_combined_methods_ratio.rds` files are used as input for the plotting and comparison scripts above.
